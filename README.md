# Simulateur d'épargne retraite

Application web statique pour simuler l'évolution d'une épargne retraite avec différentes sources de revenus, des cotisations annuelles et une phase de décaissement.

## Fonctionnalités

- Simulation de l'accumulation avant la retraite.
- Prise en compte de plusieurs comptes: CELI, REER et compte non enregistré.
- Paramètres de retraite: retrait annuel, rendement, inflation.
- Calcul de la RRQ / RPC et de la PSV.
- Interface en français, pensée pour fonctionner directement dans le navigateur.

## Utilisation locale

Le projet ne nécessite aucune installation ni compilation.

1. Ouvre `index.html` dans ton navigateur.
2. Modifie les valeurs dans le formulaire.
3. Lance la simulation avec les boutons de l'interface.

## Structure

- `index.html` : structure de l'application.
- `styles.css` : styles et mise en page.
- `script.js` : logique de calcul et interactions.

## Déploiement sur GitHub Pages

1. Pousse le dépôt sur GitHub.
2. Va dans `Settings` > `Pages`.
3. Dans `Build and deployment`, choisis `Deploy from a branch`.
4. Sélectionne la branche `main` et le dossier `/root`.
5. Attends la fin du déploiement, puis ouvre l'URL fournie par GitHub Pages.
